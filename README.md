# Копилка

Личное приложение для учёта финансов. React + TypeScript + Vite, mobile-first.

## Запуск

Требуется Node.js 22.12+.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Проверки: `npm test` и `npm run build`.

## Первая версия

- Обзор баланса, доходов, расходов и категорий за выбранный месяц.
- Операции с поиском, фильтрами и удалением с пересчётом балансов.
- Мастер: название → категория → подкатегория → сумма и счёт.
- Одна похожая операция: переносит категорию, а сумму и счёт пользователь задаёт сам.
- Удержание «+» 420 мс, движение пальца и отпускание на типе → полная форма. Также меню открывается через Shift+Enter на кнопке и из настроек.
- Типы: расход, доход, перевод, получение кредита.
- Счета с начальным остатком, локальное сохранение, экспорт JSON, отдельная загрузка демоданных.
- Настройки категорий и подкатегорий: создание, переименование с обновлением истории, удаление неиспользуемых категорий.
- Подключение существующего шаблона Google Таблиц: ручная загрузка и отправка новых операций. Настройка входа: [docs/GOOGLE_SHEETS.md](docs/GOOGLE_SHEETS.md).
- Импорт JSON и полноценный учёт погашения кредитов — следующие этапы.

Данные хранятся в localStorage этого браузера. Обмен с Google Таблицей запускается вручную после подключения. Очистка данных браузера удалит их. Экспорт JSON позволяет сохранить копию; импорт пока не реализован. Начальные остатки не привязаны к дате: общий баланс отражает все операции, месячный фильтр применяется к доходам/расходам и списку.

Решения и источник требований: [docs/DECISIONS.md](docs/DECISIONS.md).
